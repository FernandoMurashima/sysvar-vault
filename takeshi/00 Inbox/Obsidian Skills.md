# Obsidian Skills

## Resumo

Repositório com skills para ensinar agentes compatíveis a trabalhar com formatos do Obsidian e ferramentas relacionadas.

## Pontos-chave

- Inclui skills para Markdown do Obsidian, Bases, JSON Canvas, Obsidian CLI e Defuddle.
- A instalação para Codex consiste em copiar o diretório `skills/` para o caminho de skills do Codex.
- Para este cofre, as skills instaladas servem como base para ingestão, edição e leitura contextual de notas.
