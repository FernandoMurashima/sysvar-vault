# Contexto para Agentes

Este cofre guarda contexto operacional e técnico para ajudar agentes a trabalhar com projetos, código, documentação e materiais de estudo.

## Ordem de leitura

1. Ler esta nota.
2. Ler [[Mapa do Cofre]].
3. Ler [[Convenções]] se a tarefa envolver criar, editar, mover ou classificar notas.
4. Buscar termos relevantes com `rg` antes de abrir muitas notas.
5. Ler as notas mais específicas do projeto, área ou recurso relacionado.

## Regras

- Usar `C:\Takeshi\takeshi` como raiz do cofre.
- Não fazer leitura ampla do cofre sem necessidade.
- Para projetos ativos, começar em `10 Projetos`.
- Para material recente, verificar `00 Inbox`.
- Para referências técnicas, verificar `30 Recursos`.
- Para features em projetos com código, usar `$project-context-pack` para ler ou atualizar o contexto canônico antes de planejar.
- Quando o pedido de feature estiver ambíguo, usar `$grill-me` ou `/grill-me` para entrevistar o usuário antes do plano.
- Ao responder, informar brevemente quais notas foram usadas como contexto.
